# Pico-2-USBA-USBC-Firmware
This is a working firmware for Sunone's aimbot 2, working all games including Fornite.

# Setup Input Method
- Mouse Input: RP2350
- Port: Open Device Manager, look under Ports (COM & LPT), usually USB Serial Device (COM3)
- Baudrate: 921600
- RP2350 17-bit Mouse: OFF
- RP2350 Enable Keys: OFF
